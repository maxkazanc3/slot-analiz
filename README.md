# Slot Analiz Programı

## Çalıştırma

1. `npm install`  
2. `npm run dev`  
3. Tarayıcıda `http://localhost:3000` açın.  

## Deploy

1. Vercel hesabınıza giriş yapın  
2. Yeni proje oluşturun ve bu klasörü yükleyin  
3. Deploy butonuna basın, otomatik deploy olur  
4. Uygulamanız canlı, çalışır halde!
